# My Journey into React

Hello there! This is my first blog post.

I recently spent many hours fixing weird layout bugs in my portfolio website. It was painful but I learned a lot about React and CSS.

## What I learned

- Never put multiple conditional components directly without a wrapper
- `min-height: 100vh` is your best friend
- Sometimes the simplest fix is wrapping everything in one div

The debugging experience was frustrating but very educational.

I'll be sharing more such stories and learnings in future posts.
